## 🔬 Key Features

### 1. IUPAC-Compliant High-Precision MW & Stoichiometry Engine
* Full periodic table coverage (**all 118 elements**, H through Og).
* Automatic MW derivation directly from SMILES or drawn structures.
* Real-time calculation of equivalents, target mass/volumes, actual weights, and theoretical/actual yields.

### 2. Built-in Ketcher Structure Editor
* Draw chemical structures and reaction schemes seamlessly inside the desktop app.
* Seamless conversion between chemical structures and SMILES.

### 3. Multi-Step Synthetic Route & Condition Tracking
* Organize complex multi-step reactions (Step 1 to Step 20) with visual reaction arrows.
* Record solvents, temperatures, and atmospheres (Air, $N_2$, $Ar$, $H_2$).

### 4. Raw Analytical Data Attachments
* Attach TLC plate photos, NMR spectra, HPLC traces, CSVs, and PDFs directly to each experiment note.
* High-resolution local image previews.

### 5. Hazard & Chemical Master Database
* Built-in inventory for frequently used reagents, CAS numbers, and storage locations.
* Auto-flagging for hazardous, toxic, or regulated reagents.
